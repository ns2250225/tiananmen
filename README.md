# 国庆 · 天安门的一天 — National Day · A Day at Tiananmen Square

以国庆节 + 天安门广场为主题的 2D 像素动态网页（“国庆像素动态壁纸”）。默认按 **北京时间（Asia/Shanghai）** 自动运行。

## 运行

```bash
npm install
npm run dev      # 开发
npm run build    # 产物在 dist/，可直接部署到 GitHub Pages / Cloudflare Pages / Vercel / Netlify
```

## 功能一览

- **昼夜光影**：天空逐像素插值 + Bayer 抖动渐变；日出 / 日落按北京经纬度与日期实时计算；环境光 multiply 染色；黄昏游客剪影
- **太阳 / 月亮**：弧形轨迹（坐北朝南，东方在画面右侧），真实月相，像素光晕
- **天安门**：程序化手绘像素城楼（重檐歇山顶、券门、华表、金水桥、灯笼）+ 夜间泛光灯光层（灯光 0→100% 渐亮约 7 秒）
- **国旗**：按国旗法比例栅格化，3 档风力 × 8 帧庄重飘动
- **升旗 / 降旗仪式**：日出时刻自动开始（约 80 秒精简版）：游客驻足、护卫队出场、镜头推近 1.15×、国旗随国歌升起；日落降旗
- **NPC 生态**：最多 150 人，IDLE / WALK / PHOTO / WAVE_FLAG / LOOK 状态机，结伴、儿童跑动挥旗、拍照闪光、透视缩放与阴影
- **烟花**（21:00–23:00 国庆庆典艺术场景）：11 种像素烟花、30–60 秒一次高潮、环境光照与地面倒影
- **随机事件**：鸽群、阵风落叶、游客涌入、摄影闪光、云遮太阳、小朋友跑过、集体挥旗、流星、飞机、长安街车流
- **彩蛋**：连续点击天空 5 次放飞鸽群；点击月亮出现流星；点击云朵轻轻抖动；烟花按钮立即释放一枚烟花
- **时间切换**：现在 / 清晨 / 上午 / 下午 / 黄昏 / 夜晚 / 烟花（2 秒平滑过渡）+ 04:00→次日 04:00 时间滑杆 +「回到现在」
- **国庆特别模式**（10 月 1 日自动开启）：游客 +30%、小红旗 +50%、灯光增强、横幅、年份与周年数动态计算
- **声音**：Web Audio 实时合成风、人群、鸟鸣、秋虫、烟花、正步声；总音量 / 环境音 / 烟花 / 仪式音频四路混音（声音按钮单击切换，长按打开混音台）
- **其他**：📷 保存此刻（带节日落款）、全屏、性能自动降级（Ultra/High/Medium/Low）、手机竖屏适配、闲置自动隐藏 UI

## 国歌音频

项目已内置 `public/audio/ceremony/anthem.mp3`：美国海军乐队演奏的《义勇军进行曲》器乐版（Wikimedia Commons，Public domain，约 44 秒）。升旗仪式时国歌与国旗同步——国歌开始时国旗起升，国歌结束时到达顶端；国歌不会作为背景音乐循环。如需替换为其他官方录音，覆盖同名文件即可。

## 快捷键与调试参数

- 快捷键：`F` 全屏、`M` 切换音量、`T` 时间面板、`空格` 放烟花
- URL 参数：`?t=06:09:30` 起始模拟时间、`?date=2026-10-01` 指定日期、`?nd=1|0` 强制国庆模式、`?q=low|medium|high|ultra` 画质、`?autostart` 跳过入口
